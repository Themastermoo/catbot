Catbot 0.2.3 adds Burst mode and improves compatibility with local chat models.

- Use `/burst` to split a job into parts. Up to five parts start automatically, and larger plans open for review. Catbot runs up to three parts at once and combines their results in the original chat.
- Local models that reject both tool calls and streamed usage reporting can now finish a text reply whichever option they reject first.
- Local AI settings skip discovery requests triggered by unrelated chat activity. Checking whether an engine is in use now reads one database result, including when its only bot is archived.
- Adding Ollama and LM Studio at the same time preserves both selections.

Choose Update when Catbot offers the new version, or download the package for your platform from the release. This version uses the same chat storage format as 0.2.2.
